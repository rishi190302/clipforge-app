Getting started: make your first Short
This guide takes you from the portable ClipForge download to an exported
vertical video. You do not need to create an account or configure an API
key to use the studio.

1. Download and open ClipForge
Open the latest ClipForge release.
Download the Windows portable ZIP.
Extract the ZIP to a folder you can find again, for example
C:\ClipForge.
Double-click ClipForge.vbs. ClipForge opens in your browser.
There is no installer and administrator access is not required. Keep the
extracted folder in place while you use ClipForge.

If Windows SmartScreen warns that the launcher is unsigned, see the
Troubleshooting section in the README before
deciding whether to run it. You can verify the release ZIP against its
published SHA-256 checksum.

2. Open the Studio
Choose the Studio tab, then open the Video Editor. The Studio works
locally on your PC: your clips and project files stay in the ClipForge
folders unless you enable an optional online feature.

For a first export, use a short sample clip or a copy of a video. This
makes it easier to check the result without waiting for a long render.

3. Choose your source folder
In the Simple workflow, start with Folder:

Choose the folder containing the video clips you want to edit.
Check the displayed folder name and file count.
Make sure the folder contains the clips you intend to process.
ClipForge works from a folder of videos. If you are experimenting, put
only your test clip in a separate folder so you do not accidentally
process unrelated footage.

4. Choose where the video should go
Move to Where the videos go and select the vertical target for a
Short.

A vertical export is made in a 9:16 frame (1080 × 1920 by default). If
your source is horizontal, check the preview carefully: a normal
vertical crop can cut off the sides. Use the fit/blur-background option
in the advanced controls when you need to keep the complete horizontal
picture visible inside a vertical frame.

5. Pick a look
In Look, choose one of the available look cards or a saved style.
The preview lets you check the result before rendering.

If the preview does not look right, try another look or switch to
Advanced to adjust individual settings. You can return to Simple mode
when you are ready to export.

6. Run the export
The final step shows a summary of the work, for example the number of
selected files multiplied by the number of targets.

Check the summary.
Start the run.
Let the render finish. Do not close ClipForge while it is
processing.
Open Outputs to find and play the exported video.
The output is written to the ClipForge workspace, not over your original
source clip. Check the exported file before uploading it to YouTube,
Instagram or TikTok.

If something does not work
ClipForge does not open: check the README troubleshooting steps
for Windows SmartScreen and antivirus warnings.
The preview is blank or slow: try a shorter clip and check that
the source video can play on your PC.
The vertical crop cuts off the subject: use the
fit/blur-background option in Advanced rather than a centre crop.
The export is slow: an NVIDIA GPU can accelerate supported
export codecs; CPU export is also supported.
You cannot find the result: open the Outputs tab. Your videos
and projects are stored in the ClipForge workspace folder.
For the full list of editing controls and advanced options, see the
Video Editor reference. For installation, optional
integrations and more troubleshooting, see the README.
